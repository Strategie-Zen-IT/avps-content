{{- /* URL du logo de l'employeur d'une offre, ou chaîne vide. Contexte attendu (.) : une page d'AVP. Un logo n'est affiché QUE si son employeur figure dans `data/employeurs_partenaires.yml`, le fichier unique où sont notés les accords obtenus et les consignes de design. Reproduire l'emblème d'une collectivité sur un site qu'elle n'édite pas suppose son accord : republier des avis de vacance de poste ouverts est licite, cela ne vaut pas licence sur les marques. La liste est vide par défaut, donc aucun logo n'apparaît tant qu'un accord n'a pas été obtenu — voir la page publique « Employeurs publics ». Le JSON-LD écrit par le moteur porte encore un champ `hiringOrganization.logo` pour tout le monde : il n'est volontairement PAS utilisé ici, et il est retiré de ce que le site publie (voir `custom-header.html` et `single.avp_json.json`). Deux clés sont essayées, dans cet ordre : le sigle de l'employeur, puis le nom de la collectivité, l'un et l'autre slugifiés. Le fichier doit exister réellement : on ne devine jamais un logo, même pour un employeur autorisé. Renvoie "" quand il n'y a rien à afficher. C'est le cas courant, et les gabarits affichent alors le symbole neutre de `avp-logo-bloc.html`. */ -}} {{- $page := . }} {{- $logo := "" }} {{- $partenaires := hugo.Data.employeurs_partenaires.employeurs | default dict }} {{- $sigle := $page.Params.employeur_sigle | default "" }} {{- $nom := $page.Params.collectivite | default "" }} {{- range slice ($sigle | urlize) ($nom | urlize) }} {{- if and (not $logo) . }} {{- with index $partenaires . }} {{- with .logo }}{{ with .fichier }} {{- if fileExists (printf "static/logos/%s" .) }} {{- $logo = printf "logos/%s" . | relURL }} {{- end }} {{- end }}{{ end }} {{- end }} {{- end }} {{- end }} {{- return $logo }}
